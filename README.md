# astrbot-plugin-random-share

让机器人「刷 B 站」并把视频分享到指定群或私聊。

不是推荐流，而是从 **B 站热门榜** 里随机挑一条，配上封面、标题、链接和一句吐槽发出去。

## 功能

- **随机排期**：周中 16:00 起、周末 12:00 起，最晚到次日 00:30
- **按次分配**：1 次偏白天、2 次前后各一、3 次白天两条晚上一条
- **群白名单**：只发列表里的群 / 人，留空则不发
- **每日额度**：每个群每天最多 N 条（默认 3），发送成功才计数
- **群内冷却**：同一群 60 秒内只能手动刷一次（私聊不限）
- **图文发送**：封面图（480×270）+《标题》+ UP 主 + 时长 + 链接，吐槽单独一条
- **模型工具**：注册 `share_random_bilibili_video`，让模型自己判断何时该发
- **关键词兜底**：`@机器人 刷个视频` / `来条恐怖视频` 也能触发
- **暂停开关**：`刷视频 off` / `刷视频 on`

## 安装

放到 AstrBot 插件目录：

```
<AstrBot>/data/plugins/astrbot_plugin_random_share/
```

重启 AstrBot 或到 WebUI 插件页重载。

依赖：`httpx`、`Pillow`（AstrBot 环境里通常已有）。

## 配置

在 WebUI 插件配置里填，或改 `data/config/astrbot_plugin_random_share_config.json`。

| 键 | 默认 | 说明 |
|---|---|---|
| `group_whitelist` | `[]` | 允许发送的群号 |
| `private_whitelist` | `[]` | 允许发送的私聊 QQ 号 |
| `weekday_max` | 2 | 周一到周四每天最多几条 |
| `weekend_max` | 3 | 周五到周日每天最多几条 |
| `weekday_start` | `16:00` | 周中时间窗开始 |
| `weekend_start` | `12:00` | 周末时间窗开始 |
| `daytime_end` | `22:00` | 白天段结束，之后算晚间段 |
| `quiet_after` | `00:30` | 最晚发送时间（次日） |
| `day_weight` | 68 | 单次时落在白天段的百分比 |
| `group_daily_limit` | 3 | 每群每天最多几条（0 = 不限） |
| `cooldown_seconds` | 60 | 群内手动刷视频冷却 |
| `min_duration_min` / `max_duration_min` | 1 / 30 | 视频时长过滤 |
| `ai_caption` | true | 是否让模型写一句吐槽 |
| `caption_provider` | 空 | 写吐槽用的模型，留空用 `deepseek/deepseek-flash` |
| `blacklist` | 直播回放/广告/恰饭 | 标题黑名单 |

## 使用

定时：按排期自动发，不需要操作。

手动：

```
@机器人 刷个视频
@机器人 来条恐怖视频
@机器人 给我分享个游戏视频
```

控制：

```
刷视频 off   # 停止定时
刷视频 on    # 恢复
```

模型自己判断：直接说「给我整点乐子」「无聊，看个视频」，模型会调用工具发一条。

## 成本

| 项 | token |
|---|---|
| 拉榜单、封面 | 0（不走模型） |
| 写吐槽 | 约 300~600/条 |
| 一天 1~3 条 | 约 1000~1800 |

## 已知问题

- **B 站热门接口非官方**，接口字段变了就会失效；目前无重试之外的兜底
- **卡片形式做不到**：试过 `structmsg` 和 `miniapp` 两种 JSON，QQ 都回「发送者版本过低」，机器人账号没有发分享卡片的权限，只能用图文
- 关键词触发是**硬匹配**，说法太偏可能漏；兜底靠模型调用工具
- 群额度、冷却只在**本地状态文件**里，删了 `state.json` 就重置
- 重启后如果没有收到过任何消息，第一时间可能还拿不到平台客户端（发送会失败一次）
